# SGM (Sigerous Mod 3.10): итоговая ведомость решений

Документ закрывает вопрос по SGM: после него к моду не возвращаемся, всё нужное берём по этому списку.
Основание: `sgm_story_audit.md` (3 части), чтение скриптов SGM (`sgm_*.script`, хуки в ванильных скриптах), правила проекта (без хуков в ядро, без `actor_binder:update`, без раздувания сейвов, без новых небоевых NPC).
Проверено чтением и grep; в игре ничего из SGM не запускалось.

Обозначения: **БЕРЁМ** — переносим идею, пишем свой код; **СДЕЛАНО** — уже в аддоне; **НЕ БЕРЁМ** — закрыто; режим: Story (расширение сюжета) / Free (Freeplay) / оба.

## 1. Механики и модули

| Что в SGM | Что делает | Решение | Как у нас |
|---|---|---|---|
| Книги навыков `skill_book_*` | чтение книги даёт навык к оружию | СДЕЛАНО | `fp_skills` (меньший износ, без хуков в NPC) |
| Сытость (`sgm_effects`, `satiety_factor`) | голод, урон при голоде, еда его снимает | СДЕЛАНО | `fp_satiety` (своя, опция) |
| Чёрный день (`sgm_blackday`) | погодный эффект затмения | СДЕЛАНО (идея и эффект) | `fp_surge` |
| Сон по точкам (`sgm_sleep_places`, `sgm_effects`) | сон в известных точках, усталость | БЕРЁМ, на паузе | ждёт ваших данных по матрасам; основа ogsm_sleep + точки SGM (58 `*_sleep_N`); спальник не берём |
| Квесты (`sgm_tasks`, `sgm_world`, диалоги) | ~77 заданий | БЕРЁМ выборочно (раздел 2) | `fp_quests`: свой лёгкий слой на `CGameTask`, без `add_task` SGM |
| Вещи лидеров (`dv_*` кейсы, `deserves_manager`) | убил лидера — кейс с тайником-подсказкой | БЕРЁМ, позже | скрипт на лидеров отрядов; содержимое кейсов решаем отдельно |
| HUD (`sgm_huds`: время, подсказки) | время/индикаторы на экране | БЕРЁМ позже, по пунктам | только время и полезные индикаторы, свой код, опция `disable_hud_*` не нужна |
| Медали по рангу (`sgm_grant`) | деньги и предмет за ранг 100…1200 | БЕРЁМ, мелко | проверка ранга раз в несколько секунд в `on_update`, `fp_medals` info; деньги малые |
| Замена тайников (`treasure_*`, `personal_rukzak`) | рюкзаки-тайники | ЗАМЕНЯЕМ | обыскиваемые тела/тайники вместо хардкод-координат |
| Рандомные разведчики (`sgm_reinforcement`, `sgm_squads` explorers) | отряды появляются у точек Болот и респавнятся | НЕ БЕРЁМ | NPC «для галочки» + 232 хардкод-спавна; симуляция уже даёт отряды |
| Банкиры, телохранители, заводчики, все новые NPC | небоевые роли | НЕ БЕРЁМ | решение 27.11: роль отдаём существующим персонажам |
| Вспомогательные схемы (`xr_move`, `mob_move`, `xr_theatre`, `xr_shooter`, `xr_defender`, `ph_shot`, `ph_radio`, `ph_minigun`) | поведение NPC квестов | НЕ БЕРЁМ как слой | квест обходится штатными схемами; если конкретному квесту не хватает — пишем одну нужную схему |
| `xr_doctor`, `xr_gainer`, `xr_picker` | NPC лечат раненых, грабят трупы | НЕ БЕРЁМ | баланс, покадровая нагрузка на каждого NPC, хук в `xr_motivator` |
| `enemy_found_tips`, `npc_range_module`, `profile_update` | подсказки «враг замечен», дальность ПНВ, реестр профилей | НЕ БЕРЁМ | косметика; реестр заменяется регистрацией id при нашем спавне |
| Ремонтные наборы и бонусные предметы (`repair_*_box`, `psy_complex`, `medkit_elite`, `outfit_upgrade_*`) | восстановление состояния | НЕ БЕРЁМ | решение «всё по броне/оружию SGM кроме книг» остаётся |
| Режимы-читы (`sgm_modes`, `ui_extra_*`, читы в меню) | бессмертие, энергия, кровотечение | НЕ БЕРЁМ | для тестов есть `fp_dev` |
| Побочка диалогов: +70 репутации, +100 к отношению за каждый диалог (`dialogs.script`) | меняет баланс | НЕ БЕРЁМ | |
| Авточистка трупов 160 с, защита трупов, `death_items_grants` | квестовые трупы не исчезают | НЕ БЕРЁМ | у квестов с трупами проверим отдельно |
| Хуки ядра: `task_objects`, `task_manager`, `sim_faction`, `smart_terrain`, `xr_logic shooter_switch` | расширения заданий и логики | НЕ БЕРЁМ | у SRP свои версии, патчи не накладываются (500–3000 строк расхождения) |
| Инфо-флаги сюжета (`bandit_off`, `stalker_off`, отношения Лиманска) | сюжетные переключатели | НЕ БЕРЁМ | только Story-ветка, когда дойдём до неё |
| Подсказки/обучалки (`sgm_news`: агру-полтергейсты, красный лес кейс) | разовые обучающие ролики | НЕ БЕРЁМ | мелочь, не стоит опроса координат |
| Баланс-лут, оружие, броня, текстуры SGM | контент | НЕ БЕРЁМ | отдельная тема (OGSM, позже) |
| Предметы SGM | ~225 секций, ~18 нет нигде | БЕРЁМ только квестовые | по мере квестов, иконки в `new_items_icons.txt` |

## 3. Правила переноса (закрепляем)
1. Берём идею и схему, реализацию заменяем; буквальный порт не обязателен.
2. Координаты и вершины графа из SGM — только после сверки с all.spawn CS; при расхождении переснимаем.
3. Каждый квест — отдельный коммит: секция в `fp_quests.ltx`, диалоги, строки, info, предметы, иконки в списке.
4. Новый NPC — только если без него квест невозможен и роль нельзя отдать существующему.
5. Если квест требует чужой механики (схема, эффект), сначала ищем штатную замену, иначе пишем одну точечную функцию.

## 4. Не проверено
Вершины и позиции спавнов в графе SRP; поведение метки задания после загрузки; игровая работа любого перенесённого квеста; наличие всех текстовых строк SGM для выбранных квестов.
